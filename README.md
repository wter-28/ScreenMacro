# ScreenMacro 屏幕点击助手

一个基于 **Qt6 / C++17** 的 Windows 屏幕点击宏工具：在屏幕上取点记录坐标，再按顺序自动模拟鼠标点击，
适合重复性操作、游戏辅助、自动化测试等场景。

## 功能特性

- **全屏取点**：半透明遮罩覆盖整个虚拟桌面（支持多显示器），点击即记录**物理像素**坐标，
  进程按 DPI Aware 运行，坐标可直接交给 Win32 `SendInput` 使用
- **三种动作**：左键单击、右键单击、左键双击
- **单步精细控制**：每一步都可单独设置**重复次数**与**等待时间**（0.1 秒精度）
- **整段循环**：脚本可循环执行 1 ~ 9999 轮，并支持 0 ~ 60 秒的**开始前倒计时**
  （留出时间把目标窗口切到前台）
- **随时中断**：回放在独立线程中进行，执行期间按 **F9** 全局热键立即停止
- **脚本存档**：脚本以 JSON 保存 / 读取，方便复用与分享

## 快速开始

1. 点击「＋ 添加点击点」，屏幕变暗后，在目标位置点一下即可记录坐标（`Esc` 取消）
2. 在列表中为每一步选择 **操作** 类型、**次数**、**等待(秒)**
3. 在底部设置 **重复** 轮数 与 **开始前等待** 秒数
4. 点击「开始执行」，程序会隐藏并把焦点交还给目标窗口；需要停止时按 `F9`

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `F9` | 执行期间停止（仅在运行中注册，平时不占用系统快捷键） |
| `Esc` | 取点遮罩下取消本次取点 |

## 脚本格式

脚本为 JSON 文件（`.json`），结构如下：

```json
{
  "version": 1,
  "loop": 3,
  "startupDelay": 3,
  "steps": [
    { "x": 800, "y": 450, "action": "left",   "repeat": 1, "wait": 1.0 },
    { "x": 1200, "y": 600, "action": "double", "repeat": 2, "wait": 0.5 },
    { "x": 100,  "y": 100, "action": "right",  "repeat": 1, "wait": 2.0 }
  ]
}
```

- `action`：`left`（左键单击）/ `right`（右键单击）/ `double`（左键双击）
- `wait`：该步执行完成后等待的秒数
- `repeat`：该步重复执行的次数

## 编译

依赖 **Qt6（Widgets 组件）** 与 **CMake 3.19+**，使用 C++17：

```bash
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

> 仅支持 Windows，内部使用了 Win32 API（`SendInput` / `SetCursorPos` / `RegisterHotKey`）。
